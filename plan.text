# OpenBoatUtils behavioral parity on Horizon and Nova-iOS

Target Minecraft 26.3. Use stable OpenBoatUtils main, protocol 22, unstable=false, as the behavioral reference. The first racing priority is mixed-surface contact. Java substitutes each touching block's friction before the engine averages contacts and classifies the medium. The port changes the average afterward, sometimes using one block at the hull center. Crossing a dirt/ice seam can already change speed and the tick on which the boat leaves land.

This is a source audit and implementation handoff. No Fabric replay, real server exchange, packaged WASM run or physical iOS race was executed during the audit. "Full" below applies only to the named boundary. No end-to-end race has been certified.

## Operation inventory and regression fixtures

IDs below are the signed big-endian short on each channel. Fields after the ID use network byte order. f32/f64 are IEEE binary32/binary64. str is a Minecraft length-prefixed UTF-8 string. A compound body starts with an i32 child count followed by the encoded children in order. The boolean reader treats nonzero as true.

Full = behavior established at the stated boundary. Partial = identifiable working subset. Incorrect = implemented algorithm with a demonstrable counterexample. Missing = effect absent, including decoded/discarded or stored/unused fields. Run each row from a real incoming packet on the packaged guest. Compare state, replies and the consuming tick with the reference.

## Per-tick simulation specification

1. Establish inactive versus active vanilla. Inactive context bypasses most mixins. Vanilla values on activation are fall damage true, default friction .6f, gravity force -0.03999999910593033 (f64), yaw 1f, forward .04f, backward and turn-forward .005f, collision mode vanilla, resolution 1, jumps 1, scale/step-up/lateral/brake 1f, max speed -1f, resistance 0. Jump, step, swim, walltap and coyote are zero. Other optional flags start false. Seed block friction with every registry entry whose value differs from .6f. applyFrom copies explicit settings, in-use flags and filters. Include active vanilla in goldens even when nominal constants look like the host defaults.

2. Evaluate contacts before effective location. Make the slab [minY-.001, minY] using full hull X/Z. Pad floor minima and ceil maxima by one block, traverse X then Z then Y, skip corner columns and the outer top/bottom edge cells. Skip lily pads and require a nonempty voxel-shape intersection. Count each contacting block once. Sum in f32 and divide by the f32 count. Each missing per-block value uses the context fallback; zero contacts use the air override/fallback. Max reductions start at +0f for a nonempty hull, which matters for all-negative overrides. Preserve Java rounding for negative half values and integer behavior at limits. Contact selection tests must include slab/stair boundaries, a six-block ordinary floor, ice/slime seams, negative coordinates, zero effective friction and hull scale changes.
